# Liquid Logic

Παζλ ταξινόμησης χρωματιστών υγρών σε μπουκάλια για **Amstrad CPC 6128**,
γραμμένο σε Z80 assembly.

Μεταγγίζεις υγρά από μπουκάλι σε μπουκάλι ώσπου κάθε μπουκάλι να περιέχει ένα
μόνο χρώμα. Το υγρό ρέει σαν αληθινός πίδακας: σωματίδια με βαρύτητα που
διαγράφουν τόξο, πιτσιλίζουν στην επιφάνεια και ανεβάζουν τη στάθμη γραμμή-γραμμή.

## Πώς παίζεται

Από τον τίτλο, SPACE για την επιλογή πίστας, ή R για τη **«Χαλάρωση»**:
ατέλειωτες τυχαίες πίστες, χωρίς αστέρια και χρόνο. Ξεκινάς από την 1· κάθε πίστα
που λύνεις ξεκλειδώνει την επόμενη και κερδίζει ως 3 αστέρια, ανάλογα με το
πόσο κοντά στις ελάχιστες κινήσεις (par) την έλυσες.

1. Με τα **βελάκια** μετακινείς τον κέρσορα στα μπουκάλια (← → στη σειρά, ↑ ↓ αλλάζει σειρά).
2. **SPACE**: επιλέγεις το μπουκάλι **από το οποίο** θα αδειάσει (σηκώνεται).
3. Μετακινείσαι και πατάς **SPACE** στο μπουκάλι **στο οποίο** θα αδειάσει.
4. Το μπουκάλι πετάει δίπλα στον στόχο, γέρνει και αδειάζει, και γυρίζει πίσω.
   Μεταγγίζεται όλη η επάνω στρώση του ίδιου χρώματος, αν το μπουκάλι-στόχος
   είναι άδειο ή έχει το ίδιο χρώμα επάνω, όσο χωράει.

| Πλήκτρο | |
|---|---|
| Βελάκια / joystick | κέρσορας |
| SPACE / fire | επιλογή πηγής, μετά στόχου |
| ESC | ακύρωση επιλογής· χωρίς επιλογή: παύση |
| M | στη νίκη ή στην παύση: επιλογή πίστας |
| U | undo (5 ανά πίστα) |
| R | restart πίστας· στον τίτλο: «Χαλάρωση» |
| E | έξτρα άδειο μπουκάλι (μία φορά, όπου το HUD δείχνει `E+`) |

## Τύποι πιστών

| Τύπος | Πώς φαίνεται | Κανόνας |
|---|---|---|
| Κρυμμένες στρώσεις | σκούρο κυανό με «?» | αποκαλύπτονται όταν βρεθούν στην κορυφή· η μετάγγιση σταματάει σε κρυμμένη |
| Πάγος | λευκοί κρύσταλλοι και αριθμός | ούτε πηγή ούτε στόχος για τόσες κινήσεις |
| Λουκέτο | λουκέτο σε ένα χρώμα | ανοίγει όταν ολοκληρωθεί μπουκάλι με αυτό το χρώμα |
| Όριο κινήσεων | `LEFT n` στο HUD | στο 0 χωρίς νίκη: U ή R |
| Ψηλά μπουκάλια | λεπτότερες στρώσεις | 5 ή 6 στρώσεις |
| Μικτές χωρητικότητες | εγκοπές στους τοίχους | μικρά μπουκάλια 2–3 στρώσεων |
| Σταγονόμετρο | λευκός βολβός | μία στρώση τη φορά |
| Κουρτίνα | ρίγες σε όλο το σώμα | φεύγει στην πρώτη μετάγγιση σε/από αυτό |
| Χρονόμετρο | `TIME n` στο HUD | στο 0: R |

Οι 100 πίστες τους εισάγουν έναν-έναν (3 ως 12 χρώματα) και μετά τους
συνδυάζουν· κάθε 10η πίστα είναι «Πρόκληση».
Λεπτομέρειες στο [plan.md](plan.md).

## Build

Απαιτούνται:

- [rasm](https://github.com/EdouardBERGE/rasm) (≥ 2.x) — γράφει τα binaries κατευθείαν σε Extended DSK
- [iDSK](https://github.com/cpcsdk/idsk) — προσθέτει τον BASIC loader
- Python 3 — για την παραγωγή γραφικών/πιστών (`make assets`)

```bash
make
```

Βγάζει το `build/LiquidLogic.dsk` (Extended DSK). Στον CPC 6128 ή σε emulator:

```
RUN"DISC
```

Άλλοι στόχοι:

```bash
make assets   # ξαναπαράγει γραφικά, πίνακες φυσικής και πίστες (assets/data)
make shot     # headless emulator -> build/screenshot.png
make shot32   # Caprice32 χωρίς παράθυρο -> build/cap32_*.png
make test     # headless emulator: λύνει και τις 100 πίστες, ελέγχει κάθε ειδικό τύπο και τη «Χαλάρωση»
make sound    # headless emulator: μουσική τίτλου και πίστα 1 -> build/sound_*.wav
make clean
```

## Δομή

```
src/          Z80 πηγαίος κώδικας (main, hw, screen, particles, ...)
assets/src/   Python που παράγει τα γραφικά
assets/data/  παραγόμενα δεδομένα (db) για το rasm
tools/        γεννήτρια πιστών με solver, headless test
docs/         εγχειρίδιο (manual-el.md, manual-en.md)
plan.md       σχέδιο ανάπτυξης και ορόσημα
```

## Κατάσταση

Όλα τα ορόσημα M0–M9 του [plan.md](plan.md#9-ορόσημα) είναι έτοιμα: 100
πίστες, ειδικοί τύποι, ήχος, αποθήκευση προόδου, 64 σωματίδια, πτήση και
γέρσιμο του μπουκαλιού, διαβάθμιση φόντου, «Χαλάρωση». Ελεγμένο στον headless
emulator (λύνει όλες τις πίστες) και στον Caprice32· όχι ακόμα σε πραγματικό
CPC. Εγχειρίδιο: [ελληνικά](docs/manual-el.md), [English](docs/manual-en.md).
